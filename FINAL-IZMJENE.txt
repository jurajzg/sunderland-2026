SUNDERLAND 2026 – KONAČNI PAKET IZMJENA

ŠTO JE PROMIJENJENO
- Dodan Cloudflare Pages Function endpoint na /api/* (functions/api/[[path]].js).
- API koristi isti origin kao web-stranica; nema više cross-site cookie / workers.dev konfiguracije.
- Sesijski cookie: HttpOnly, Secure, SameSite=Strict.
- PIN provjera koristi PBKDF2-SHA256 sa soli (format pbkdf2-sha256$iteracije$sol$hash).
- Dodana provjera Origin zaglavlja za browser POST zahtjeve.
- Ispravljena kategorija ulaznica za Letove; API prihvaća flight, train i match.
- Ispravljena obrada isteka blokade PIN pokušaja.
- PDF-i ostaju u privatnom R2; ZIP ne sadrži stvarne ulaznice ni tajne.
- Početna stranica i CSS nisu redizajnirani.

OBAVEZNO PRIJE KORIŠTENJA
1. Zamijeni sadržaj repozitorija ovim paketom i pushaj na main.
2. U Cloudflare Pages dodaj D1 binding DB i R2 binding BUCKET.
3. U Pages Secrets dodaj TICKET_PIN_HASH i ADMIN_TOKEN_HASH; u Variables dodaj ALLOWED_ORIGIN.
4. Primijeni D1 migracije ako tablice već ne postoje.
5. Provjeri /api/health i napravi testove iz README.md.
6. Tek nakon uspješnih testova učitaj PDF-ove administratorskom skriptom.
